# Patient Dashboard

## Project Overview
Patient Dashboard is a front-end web application designed to provide a simple and user-friendly interface for viewing and managing patient-related information.

## Features
- Clean and user-friendly dashboard interface
- Organized patient information display
- Responsive layout
- Easy navigation

## Technologies Used
- HTML
- CSS
- JavaScript
- React / Vite (if used in this project)

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/kancharla-Harshitha/patient-dashboard.git
   ```

2. Navigate to the project folder:
   ```bash
   cd patient-dashboard
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
